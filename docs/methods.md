# Methods



DICOM-Sentinel is an auditing framework for paired evaluation of DICOM privacy transformation, residual linkability, structural integrity, controlled tampering sensitivity, pixel preservation, analytical utility, and external validation. It is not a de-identification tool and does not modify source DICOM files as part of the frozen analyses.



The development evaluation uses paired Evaluation and De-identified instances from the TCIA Pseudo-PHI-DICOM dataset. External validation uses paired Synthetic Validation and Curated Validation instances from MIDI-B. Official Patient-ID and UID crosswalks are used for reference pairing and audit validation. They are not used as predictors in linkage models.



The repository contains the final scripts only. Dataset files, source DICOM objects, answer databases, and official mapping files are excluded from redistribution.
